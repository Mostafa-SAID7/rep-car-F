# Auto AI documentation

This folder contains the project documentation that should stay useful as the application grows.

## Start here

- [`architecture.md`](architecture.md) — application boundaries, route ownership, and data flow
- [`development.md`](development.md) — setup, commands, conventions, and verification
- [`ai-features.md`](ai-features.md) — Gemini capabilities, environment configuration, and security boundary

## Documentation principles

- Document decisions and boundaries, not implementation trivia.
- Keep commands copyable and aligned with `package.json`.
- Update docs when a route, external service, or local setup requirement changes.
- Never put secrets, real API keys, or private user data in documentation.
